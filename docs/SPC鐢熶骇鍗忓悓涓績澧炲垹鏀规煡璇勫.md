# SPC 生产协同中心增删改查评审

## 结论

当前接入按“只读分析链路”交付，不新增 SPC 业务数据的创建、修改、删除接口。生产工单、工序、订单关联、报工、产能五类能力均通过 `company-control` MCP 的 `READ_ONLY` 工具读取，并要求保留 `evidence_refs`、`data_as_of`、`data_confidence` 和 `stale` 口径。

## 已具备的能力

| 范围 | 能力 | 权限 |
| --- | --- | --- |
| 生产工单 | `production_work_orders_list` | 查询 |
| 工序进度 | `production_operations_list`，必须以 `order_no` 锚定 | 查询 |
| 工单与订单关联 | `production_order_links_list`，必须提供工单号或订单号 | 查询 |
| 生产报工 | `production_reports_list`，必须以 `work_order_no` 锚定 | 查询 |
| 产能 | `production_capacity_list`，必须提供日期窗口 | 查询 |
| AEOS 港湾 / 小队 | Agent、成员、绑定、记忆、活动和运行状态 | 配置治理 |
| 经营事项中心 | 只读风险建档、人工确认、状态维护 | Hub 内部治理 |

港湾、小队和经营事项中心的写操作只改变 AEOS 的编排或人工治理记录，不会写回 SPC、ERP 或 OA 业务数据。

## 暂不开放的业务写操作

以下接口在中台提供完整契约前不接入：创建/修改/删除工单、改工序状态、补报工、撤销报工、修改产能、修改工单与订单关联、批量关闭生产异常。

若后续要开放，至少需要中台提供：`endpoint_code`、字段字典、角色和权限、幂等键、审批要求、前后状态、审计字段、取消/回滚语义、重试规则，以及写入后的可查询 `evidence_ref`。没有这些字段时，Hub 只能继续给出建议动作并要求人工在中台执行。

## 对接验收口径

1. 空结果不能解释为“没有阻塞”；必须同时检查 `data_as_of`、`data_confidence`、`stale` 和 `evidence_refs`。
2. 工序查询使用销售订单号，报工查询使用生产工单号；禁止用产品编码猜测关联。
3. 生产 Agent 只调用五个生产只读工具，输出事项、证据、影响、建议动作、责任角色、时效和置信度。
4. 看板展示工单与产能汇总，详细工序与报工由生产 Agent 按锚点下钻。
5. 任何业务处置由中台业务负责人审批并在中台完成，AEOS 不声称已执行。
