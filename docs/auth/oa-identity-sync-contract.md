# OA 人员身份同步契约

## 数据权威与流向

数据只允许单向流动：公司 OA 只读视图 → OA 适配器 → Keycloak 人员投影 → Hub 用户管理。Hub 不写 OA 数据库，浏览器不接触数据库地址、账号或密码。

- OA 权威字段：不可变员工 ID、显示名、部门、岗位、组织结构、在职状态、更新时间。
- Keycloak 权威字段：稳定用户 ID、用户名、密码或外部身份、登录会话、账号启停、角色分配。
- Hub 权威字段：权限资源树、角色权限、G0/G1 决策、业务留痕。

同步以 `externalEmployeeId` 唯一定位人员，不以姓名或可变登录名匹配。一次增量批次必须先全部校验；出现重复 ID、字段不合法或来源不可用时不推进游标。离职/停用记录只将 Keycloak 用户置为 disabled，不删除用户及历史 Evidence。同步只更新 OA 所属属性，不触碰密码、凭据、现有角色和权限授权。

## 接入真实 OA 前必须提供

1. 数据库引擎与版本、非生产连接地址及网络访问方式。
2. OA 方批准的只读数据库账号，以及只读员工/组织视图；不得直接读取无约束的业务表。
3. 不可变员工唯一 ID、租户与组织映射规则、在职状态规则。
4. 可用于增量同步的更新时间列、递增游标或变更表，以及相同时间戳的稳定排序键。
5. 字段字典、空值规则、历史保留、同步周期、失败告警与恢复负责人。

当前仓库只实现数据库无关接口、校验、Keycloak 安全投影和持久化游标状态；未选择驱动、未保存 OA 凭据，也未猜测表名。收到以上资料后再实现具体只读适配器、初次全量命令与定时增量命令。
