# 业务视图（P0）

> 日期：2026-10-26
> 目的：让非技术管理者默认看到业务语言与业务模块，技术细节收进「完整视图」或折叠区。

## 一、默认视图

manager / supervisor / analyst 登录后默认进入**业务视图**，左侧只保留：

| 导航 | 说明 |
|---|---|
| 工作台 | 管理者首页 |
| 智能助手 | 原「中枢 Agent」 |
| 待关注事项 | 原「Attention 中心」 |
| 分析工作台 | 原「执行面仪表盘」，用自然语言提问 |
| 处理记录 | 原「链路追踪」，看一次分析的发起、依据与成本 |
| 分析成本 | 原「用量明细」，只看成本与次数 |

管理模块（跨系统查询、AI 运行观测、证据与审计、能力目录、运行状态、模型配置、系统配置、AI 资源）默认隐藏。

侧边栏底部有「**切换到完整视图 / 切换到业务视图**」按钮，状态记在浏览器本地。operator/owner 及管理员可切换；其他角色固定业务视图。

## 二、术语替换

| 原 | 新 |
|---|---|
| 中枢 Agent | 智能助手 |
| 执行面仪表盘 | 分析工作台 |
| 跨系统借调 | 跨系统查询 |
| 链路追踪 | 处理记录 |
| 用量明细 | 分析成本 |
| Evidence 证据中心 | 证据与审计 |
| Capability Registry | 能力目录 |
| AI 观测 | AI 运行观测 |
| 模型选型 | 模型配置 |
| 运行监控 | 运行状态 |

## 三、技术信息收口

- **借用详情**：主视图只显示发起方、提供方、业务能力、状态、时间；借调单号、请求编号、执行编号、能力版本、schema 哈希收进「技术信息」折叠区。
- **链路追踪**：执行 run 区块已移除，概览只保留“执行环节”数量；完整视图下提供「查看执行详情 → AI 运行观测」。
- **成本**：统一显示两位小数（如 ¥0.03）。
- **用量**：业务视图隐藏 Token 列与累计 Token 卡片，只显示成本与次数；「按智能助手」只列面向用户的助手（AEOS 智能助手、中台助手），执行通道、历史 Agent、探针与纯查询记录归完整视图。
- **证据**：推理摘要把 `control-platform://...` 翻成“中台 · 齐套结果 / 订单 / 质量异常”等来源标签；原始引用仍在原始 JSON 中。
- **错误**：常见错误码翻成业务语言（如 `CAPABILITY_FORBIDDEN` → “当前智能助手没有这项权限，请联系管理员开通”）。

## 四、验收

1. 用 `manager` 登录，左侧只有 6 个业务导航；
2. 点底部「切换到完整视图」，管理模块出现；再切回业务视图；
3. 问一句订单风险，结论里显示“依据：中台 · …”，不是 `control-platform://…`；等待时显示已等待秒数，可点「取消分析」；完成或取消后可点「查看处理记录」跳到链路；结论下方支持「复制结论」「导出结论」；
4. 跨系统查询详情里技术编号默认折叠；
5. 分析成本页不显示 Token 列；
6. 全部 `npm test` 通过（当前 exit 0）。
