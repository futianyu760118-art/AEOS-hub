# 任务与项目协同模块需求说明

## 目标

将 AEOS「任务协同」升级为可持续使用的任务管理模块，并在其下新增「项目」模块。交互形态参考用户提供的任务与项目页面截图：任务支持状态看板和列表视图，项目支持列表入口、项目内任务看板和项目详情侧栏。

## 业务能力

- 任务：创建、检索、筛选、按状态分组的看板、列表视图、优先级、负责人、截止日、项目关联、详情、状态流转和历史。
- 项目：创建、检索、状态/优先级/负责人/成员、起止日期、描述、进度、项目任务计数；项目列表与项目内任务看板。
- 任务可独立存在，也可关联一个项目；项目进度从其任务的完成状态派生，不能由浏览器任意伪造。
- 不移除既有订单风险任务闭环、证据、审计、租户隔离、G0/G1 范围门禁、M01 身份与角色授权。

## 默认授权原则

- 仅已认证的人类用户可写入；服务、系统和 Agent 身份只读。
- 管理者可创建项目、创建或重分派任务、维护项目成员；被分派经办人只能操作自己的任务；业务 Owner 保留对受控订单风险任务结果的核验权。
- 所有写操作使用服务端可信身份、租户范围检查和审计证据；浏览器请求不得提供或覆盖身份、租户或角色。

## 体验要求

- 左侧导航在「任务协同」下显示「任务」和「项目」。
- 任务页具备搜索、状态列、数量、任务卡、筛选、看板/列表切换、新建任务和详情抽屉。
- 项目页具备搜索、筛选、创建时间排序、项目表格；打开项目后显示该项目任务看板、右侧项目属性和进度。
- 保持 AEOS 的中文信息架构和既有品牌，不复制参考站点的名称、数据或受版权保护的素材。

## 验收

- 任务与项目在刷新后保持，且跨租户不可读写。
- 项目内只展示关联任务，项目进度与任务状态一致。
- 既有受控订单任务的 API、审计证据、状态机和授权测试继续通过。
- 新能力具备 Node 测试、类型检查和浏览器可操作的前端验证。
