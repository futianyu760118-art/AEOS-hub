# 反馈模块 MVP 规格

## 背景

AEOS Hub 需要一个供已登录工作区用户提交产品反馈的入口，便于收集缺陷、改进建议和使用体验。该功能只记录 AEOS Hub 本身的反馈，不触发或修改任何 ERP / MCP 业务数据。

## 用户可见行为

- 侧边栏新增“反馈中心”入口。
- 用户可选择反馈类型（问题、建议、体验、其他）、填写主题和详细说明并提交。
- 提交后显示成功提示，并在“我的反馈”列表中立刻可见。
- 用户只能通过当前 Web 会话查看自己提交的反馈；列表显示类型、主题、状态、提交时间和说明。
- 首版反馈状态固定从“已提交”开始；不包含内部受理、回复、跨用户浏览或通知能力。

## 数据与安全边界

- 仅接受 JSON 请求；由服务端生成并保存反馈归属会话，客户端不得指定归属人、状态、ID 或时间。
- 类型限定为 `bug`、`idea`、`experience`、`other`；主题为 1–160 字符，说明为 1–2,800 字符。
- 保存到 `data/feedback.json`，使用现有原子写入与备份机制；快照版本为 1，最多保存 5,000 条记录。
- GET 结果最多返回当前会话最近 100 条，按提交时间倒序。
- 每次提交追加一条不含主题和正文的 Evidence 事件，仅包含反馈 ID、类型及会话 actor；不把用户自由文本复制到审计流。
- 所有反馈页面数据通过现有访问口令、同源校验、会话 Cookie 和 `cache-control: no-store` 保护。

## 非目标

- 不对接 ERP、MCP 或外部工单系统。
- 不提供删除、编辑、附件、内部处理后台、状态流转、邮件或 IM 通知。
- 不将反馈的内容用于自动执行、业务承诺或经营结论。
