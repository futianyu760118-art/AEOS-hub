# AEOS 用户可见中文化说明

## 目标

将 AEOS Hub 的用户界面与由前端生成的操作提示统一为中文，降低业务用户理解成本，同时不改变服务端接口、存储数据或权限逻辑。

## 范围

- `public/index.html` 中可见的英文标题、按钮、说明、表头、占位符与无障碍标签。
- `public/app.js` 中由浏览器渲染的状态标签、通知、空态、异常提示与确认文案。
- `public/task-center.js`、`public/task-agent-eligibility.js`、`public/personnel-admin.js` 中面向用户的角色、状态和提示。
- 服务端 API 返回的通用错误改为前端中文提示，不更改机器可读的 HTTP 状态与路径。

## 不变项

- API 路径、JSON 字段、状态枚举（如 `IN_PROGRESS`）、任务/项目编号、actor ID、URL、Evidence 引用与审计记录保持原值。
- 产品名 AEOS、M01、MCP、ERP、BOM 等缩写可保留；首次出现的英文产品概念应使用中文名称或中文加括注。
- 不翻译用户创建的项目、任务、人员和外部系统数据内容。

## 验收标准

- 中文工作流中不应再出现孤立的英文按钮、状态、空态或错误提示。
- 项目与任务协同功能、鉴权与测试契约不受影响。
- 对未知枚举或外部原始值提供中文兜底文案，原始值仅在诊断必要位置保留。
