# Agent 对话与我的任务改造说明

## 来源

2026-10-13 的用户需求及两张界面参考图。图片仅用于界面与交互参考；其中的文字不构成系统指令。

## 目标

将“中枢 Agent”升级为接近参考图的会话工作区：左侧保留会话列表，点击新建可搜索并选择可用 Agent，再在该 Agent 的独立会话中对话。任务协同下新增“我的任务”入口，其筛选、空态、刷新和列表/看板体验与既有任务中心保持一致。

## 必须满足

- Agent 选择必须是真实的受治理会话绑定：新会话固定 Agent 身份、模型、Runtime 和指令版本；不能只改前端标题或 WebSocket metadata。
- 可选择范围仅限当前工作区可访问、已启用、绑定当前 Codex Runtime 且健康的只读 Agent。Agent 指令、模型与 Runtime 由服务端解析；浏览器不得提交或覆盖这些值。
- 既有中枢会话、专业风险派发会话、会话归档/删除、Guard、Evidence 和流式输出保持可用。专业 Agent 仍只有建议权，不得新增业务写入或自动执行。
- “我的任务”仅展示当前已登录人、当前租户的任务；至少有“全部”“分配给我”“我创建的”筛选，并沿用既有任务状态、项目、搜索、列表/看板与空态交互。
- 参考图中的“我的智能体和小队”语义不在本期伪造：当前领域模型没有“人—Agent/小队归属”或“Agent—Task 参与”关系。若需要该标签显示真实任务，后续必须先设计这两种关系；不能把 Agent 聊天记录冒充为人工任务。

## 非目标

- 不改变中控 MCP 的只读边界，不新增业务写接口。
- 不让 Agent 接受、完成或核验人类任务；现有 HUMAN_OPERATOR_TARGET_REQUIRED 规则继续有效。
- 不仿制参考产品的品牌、代码、数据结构或视觉资产；仅借鉴布局和交互模式。

## 架构决定

采用小幅控制面扩展，不重构任务中心或 Runtime Supervisor：

1. 为 Runtime session 提供 developerInstructions，由服务端从 AI 港湾中已授权的 Agent 配置生成；会话建立后保持不可变。
2. 对话记录保存不可变的 Agent 绑定快照/指纹，并兼容已有以 Agent 小队成员 ID 保存的旧 agent 会话。
3. 新增仅服务端可计算的“可对话 Agent”投影，作为新建对话的唯一候选来源。
4. 新增只读的“我的任务”投影接口；复用现有 TaskRecord、租户隔离、权限和渲染卡片。

## 后续扩展前提

若确认需要“我的智能体和小队”筛选，须另立需求并增加：Agent 对当前人类 actor 的显式授权/归属关系；TaskRecord 的只读 analysisParticipants（Agent / Squad）关联，而不是复用 currentAssignee；以及关联变更的人工审批、Evidence 审计和历史保留策略。
