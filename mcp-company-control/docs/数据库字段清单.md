# 数据库字段清单（订单 / 订单明细 / BOM）

> 类型为 PostgreSQL 原生类型；`timestamp` 均为 `timestamp without time zone`。

## 1. `sale_order`（订单表，48 列）

| 列名 | 类型 | 可空 | 注释 |
|---|---|---|---|
| `id` | integer | 否 | 主键 |
| `order_no` | varchar(64) | 否 | 订单号 |
| `customer` | varchar(128) | 是 | 客户名称 |
| `customer_code` | varchar(64) | 是 | 客户编码 |
| `department` | varchar(64) | 是 | 部门 |
| `audit_date` | date | 是 | 审核日期 |
| `owner` | varchar(64) | 是 | 负责人 |
| `status` | varchar(32) | 否 | 订单状态（默认 open） |
| `risk_level` | varchar(16) | 是 | 风险等级 |
| `data_source` | varchar(32) | 是 | 数据来源 |
| `extra_data` | jsonb | 是 | 扩展数据 |
| `created_at` | timestamp | 否 | 创建时间 |
| `updated_at` | timestamp | 否 | 更新时间 |
| `batch_no` | varchar(128) | 是 | 批次号 |
| `line_no` | varchar(32) | 否 | 订单行号 |
| `product_code` | varchar(64) | 是 | 产品编码 |
| `product_name` | varchar(256) | 是 | 产品名称 |
| `order_qty` | numeric(15,2) | 是 | 订单数量 |
| `promised_date` | date | 是 | 合同交期 |
| `planned_start_date` | date | 是 | 计划开工日期 |
| `delivery_completed_date` | date | 是 | 发货完成日期 |
| `customer_grade` | varchar(4) | 是 | 客户等级 A/B/C/D |
| `shipping_plan` | date | 是 | 出货计划 |
| `customer_inspection_date` | date | 是 | 客户验货时间 |
| `inspection_result` | varchar(64) | 是 | 客检结果 OK/NG |
| `packaging_status` | text | 是 | 包装完成状况 |
| `bom_return_date` | date | 是 | BOM 回收日期 |
| `material_ready_date` | date | 是 | 料齐套时间 |
| `shipping_status_desc` | text | 是 | 发货状态即时说明 |
| `procurement_status` | text | 是 | 采购物料齐套-总体说明 |
| `material_dates` | jsonb | 是 | 物料分类到料日期 `{电子料,SMT上线,光源,...,包材}` |
| `front_process_date` | date | 是 | 前道日期 |
| `first_article_date` | date | 是 | 首件检验日期 |
| `assembly_start_date` | date | 是 | 组装上线日期 |
| `assembly_complete_date` | date | 是 | 组装完成日期 |
| `remark` | text | 是 | 备注 |
| `order_nature` | varchar(32) | 是 | 订单性质 |
| `order_date` | date | 是 | 下单时间 |
| `risk_score` | numeric(5,2) | 是 | 风险总评分 0–100 |
| `risk_factors` | jsonb | 是 | 各因子分值明细 `{delivery_delay,shortage,process_lag,quality,eta_delay,inspection_ng}` |
| `risk_assessed_at` | timestamp | 是 | 最近风险评估时间 |
| `completed_qty` | numeric(15,2) | 是 | 完成数量 |
| `order_amount` | numeric(15,2) | 是 | 金额 |
| `is_closed` | integer | 否 | 是否关闭（0 否 / 1 是） |
| `field_synced_at` | jsonb | 是 | 字段级同步时间 `{field_name: ISO8601 str}` |
| `erp_status` | integer | 是 | ERP 订单状态（整型：0 未审核 / 1 审核 / 2 部分关闭 / 3 已关闭） |
| `erp_id` | integer | 是 | ERP 订单主键 ID |
| `is_deleted` | integer | 否 | 是否删除（0 否 / 1 是） |
