# AEOS 数据归属

| 数据类别 | 权威 Owner | Hub 的职责 |
| --- | --- | --- |
| 人员、组织、岗位、角色、租户 | M01 | 通过统一身份与授权接口读取，不维护本地权威副本。 |
| 订单、执行、交期 | 对应业务系统 | 通过批准 Capability 读取，并保留对象引用和 evidence_ref。 |
| 产品、物料、BOM、库存、供应 | 对应业务系统 | 通过批准 Capability 读取，不复制为 Hub 主数据。 |
| 质量异常、追溯、放行结论 | 质量系统 | 展示和关联证据；质量结论由质量 Owner 确认。 |
| Event、Result、Evidence、Audit | M02 或统一审计平台 | 试点期可使用 JSONL 作为临时适配存储；生产化后通过批准接口或事件通道上报。 |
| 个人偏好、导航、看板布局、短期运行状态 | AEOS Hub | Hub 可保存，但不得转化为业务主数据。 |

## 试点存储规则

`data/evidence.jsonl` 只作为 Hub 的试点 Evidence 适配存储，不作为企业级事实源。每条记录必须保留租户、对象引用、来源系统、关联编号、契约版本、证据引用和 payload hash，以支持后续迁移到 M02。
