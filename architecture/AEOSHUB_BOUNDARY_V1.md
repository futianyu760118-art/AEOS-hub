# AEOS Hub 边界 V1

## 定位

AEOS Hub 是企业统一入口与 Agent 控制面，负责展示、只读能力编排、受控协调、审批编排和自身运行配置。Hub 不是订单、客户、BOM、质量或财务主数据的权威来源。

## Hub 可以做什么

- 调用已注册且已批准的只读 Capability，形成经营分析和建议；
- 展示业务系统返回的事实、证据引用、数据时效和置信度；
- 创建受控的协同事项、审批请求和 Agent Run；
- 记录自身运行的 Event、Evidence、审计上下文和个人工作台配置；
- 将 Event、Result、Evidence 通过批准的 M02 接口或事件通道上报。

## Hub 不可以做什么

- 保存或维护订单、客户、BOM、库存、质量、财务等业务主数据；
- 直接读写其他专业系统的数据库、ORM 或内部表；
- 将模型推断表达为未经业务 Owner 验证的业务事实；
- 在试点期绕过 Guard、审批或业务 Owner 直接改变业务状态；
- 将上游不可用、数据缺失或陈旧解读为“没有风险”。

## 跨系统交互规则

Hub 与 M01、M02 和专业业务系统仅通过经批准的 API、Facade 或事件总线交互。每次跨系统调用必须具备调用主体、租户、关联编号和证据上下文；工具调用必须经过注册表和 Guard 检查。
