# AEOS 执行面智能体 · 老板接入说明

本包是一个**可独立部署的执行面智能体**：它反向连接 AEOS Hub，承载「只读查询」「只读推理」两类能力。你只需实现**自己系统的查询适配器** + **声明自己系统的查询语义**，即可让 Hub 用自然语言查询你的系统数据，界面出结果。

## 一、你要做的三件事

### 1. 配置 `.env`

复制 `.env.example` 为 `.env`，填写：

| 变量 | 说明 |
|---|---|
| `EXECUTION_WS_URL` | Hub 地址，如 `ws://<Hub主机IP>:8788/execution-agent` |
| `EXECUTION_PLANE_TOKEN` | Hub 下发的连接令牌（必须与 Hub 一致） |
| `EXECUTION_AGENT_ID` | 唯一 Agent ID |
| `EXECUTION_SOURCE_SYSTEM` | 你的系统名称 |
| `TARGET_QUERY_BASE_URL` / `TARGET_QUERY_APP_KEY` / `TARGET_QUERY_APP_SECRET` | 你系统只读查询接口的地址与凭据 |
| `TARGET_REASONING_*` | 推理接口（可选，留空则推理能力返回「未接通」） |

### 2. 写一个自己系统的查询适配器

用通用适配器 `createHttpQueryAdapter` 配你的**端点表 / 鉴权方式 / 响应映射**，不改核心代码。示例：

```js
import { createHttpQueryAdapter } from './adapters/query-adapter.js';

export function createBossQueryAdapter({ baseUrl, token }) {
  return createHttpQueryAdapter({
    baseUrl,
    endpoints: {
      '/api/boss/orders': 'boss.orders',   // path → 端点标识（或 true 表示直接用 path）
      '/api/boss/inventory': 'boss.inventory',
    },
    auth: { type: 'bearer', token },        // 或 { type: 'hmac', appKey, appSecret } / { type: 'none' }
    unwrap: (body) => body.data ?? body,    // 从响应里取出数据
  });
}
```

> 参考实现：`src/adapters/company-control-query.js`（这是中台的例子，换成你自己的即可）。

### 3. 声明查询语义（intent）+ 注册能力

在 `src/main.js` 里声明你的查询语义（让 Hub 能用自然语言理解），并带上只读约束：

```js
import { registerCapability } from './capabilities.js';
import { createBossQueryAdapter } from './adapters/boss-query.js';

registerCapability({
  name: 'query_control_platform',
  description: '精确查询本系统只读业务数据',
  inputSchema: {
    type: 'object',
    properties: {
      path: { type: 'string', enum: ['/api/boss/orders', '/api/boss/inventory'] },
      params: { type: 'object' },
    },
    required: ['path'],
  },
  constraints: { readOnly: true },
  intent: {
    paths: [
      {
        path: '/api/boss/orders',
        label: '订单',
        keywords: ['订单', 'order'],
        params: [
          { name: 'order_no', label: '订单号' },
          { name: 'status', label: '状态', enum: [{ value: 'paid', label: '已付款' }, { value: 'shipped', label: '已发货' }] },
        ],
        output: { title: ['order_no'], fields: ['amount', 'customer', 'status'] },
      },
      {
        path: '/api/boss/inventory',
        label: '库存',
        keywords: ['库存', 'inventory'],
        params: [{ name: 'sku', label: 'SKU' }],
        output: { title: ['sku'], fields: ['on_hand', 'locked'] },
      },
    ],
  },
  handler: createBossQueryAdapter({ baseUrl: config.targetQueryBaseUrl, token: config.targetQueryToken }),
});
```

- `intent.paths[].label` + `keywords` 帮助 Hub 的自然语言识别；`params[].enum` 提供枚举中英映射；`output` 提供结果展示的标题/字段顺序。
- `constraints: { readOnly: true }` 必填，否则 Hub 会拒绝派单（`WRITE_FORBIDDEN`）。

## 二、启动

```bash
docker compose -f docker-compose.example.yml up -d aeos-execution-agent
# 或直接运行： npm install && npm start
```

启动后自动：连接 Hub → 认证 → 注册 Agent 与能力 → 心跳 → 断线自动重连。

## 三、验证

- Hub 的「执行面」列表里能看到你的 Agent（在线、名称正确）。
- 在 Hub 里用自然语言问一句（如「查订单 B-100」），能返回你系统的数据。
